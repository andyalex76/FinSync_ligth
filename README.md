# 🏠 FinSync — Семейный Бюджет, Копилка & Накопления

Современная локальная (Self-Hosted) и автономная (**Offline-First PWA**) система учёта личных и семейных финансов, взаимных расчётов, кредитов и накопительных целей. Рассчитана на семью до 5 участников с основным взаимодействием через **Telegram-бота** и полноценный интерактивный **Web/PWA-дашборд**.

---

## 💎 Ключевые возможности системы

### 1. Финансовая модель и принцип «Pay Yourself First» (Сначала заплати себе)
* **Целочисленные копейки (Minor Units):** Все денежные значения хранятся строго в целых числах (`BIGINT` в БД / `number` kopecks в TypeScript), полностью исключая ошибки округления с плавающей точкой (`0.1 + 0.2 != 0.3`).
* **Модуль «Копилка / Накопления»:**
  * Операции типа `saving` (откладывание в фонд/копилку) исключаются из доступного операционного бюджета месяца, стимулируя дисциплину сбережений.
  * При этом накопления не считаются безвозвратным расходом и увеличивают общий семейный капитал и чистые активы.
  * Поддержка типов счетов: Срочный вклад под %, Накопительный счёт, Инвестиции / Брокер, Наличный резерв.
  * Автоматический расчёт прогнозируемого ежемесячного пассивного дохода по процентной ставке.
* **Категория «Кредиты/Банки»:** Выделенный учёт ипотеки, потребительских и автокредитов, кредитных карт и банковских комиссий с мониторингом лимитов.

### 2. Совместный семейный учёт и клиринг долгов (iHateMoney)
* **Роли участников:** Владелец (`owner`), Администратор (`admin`), Участник (`member`).
* **Сплиты расходов:** Разделение трат между членами семьи (поровну, фиксированными суммами или в долях).
* **Алгоритм упрощения долгов:** Автоматический клиринг взаимных задолженностей участников с вычислением минимального числа прямых переводов для полного погашения.

### 3. Локальное распознавание чеков (100% Privacy OCR)
* Полная локальная обработка фото чеков (Tesseract OCR `rus` + `eng`) без передачи персональных данных, чеков или сумм во внешние облачные сервисы.
* Автоматическое извлечение ИНН, названия торговой точки, даты, итоговой суммы и товарных позиций.
* **Правило безопасного подтверждения:** Все распознанные документы попадают в статус черновика (`review_needed`) и зачисляются в бюджет только после ручной верификации пользователем.

### 4. Интеграция с Telegram (aiogram 3)
* Быстрый ввод трат и доходов текстом: `540 Кофе`, `2800 Бензин АИ-95`, `+65000 Аванс`.
* Быстрое пополнение копилок: `+15000 копилка подушка`, `отложил 10000 отпуск`.
* Управление через команды: `/dashboard` (сводка месяца), `/savings` (прогресс целей и вкладов), приём фото чеков.

### 5. Offline-First PWA & Надежность
* Полноценная работа без подключения к интернету с локальным хранилищем `LocalStorage` и Service Worker.
* Установка как нативное приложение на iOS, Android, macOS и Windows.
* Экспорт/импорт полного резервного слепка данных в `.json` и выгрузка истории операций в `.csv`.

## 🏛️ Архитектурные принципы и репозитории-источники

| Репозиторий | Что взято и как применено |
|---|---|
| **aiogram/aiogram** | Асинхронный Telegram-бот: FSM-состояния, быстрый ввод расходов, пополнение копилок, приём фото чеков, инлайн-кнопки подтверждения черновиков. |
| **tesseract-ocr/tesseract** | Локальный OCR-движок с языковыми пакетами `rus` и `eng`. 100% локальная обработка на клиенте и сервере без утечки данных. |
| **paperless-ngx/paperless-ngx** | Пайплайн обработки документов: статусы (`pending` → `processing` → `review_needed` → `confirmed`), сохранение оригинала, сырого OCR-текста и метаданных. |
| **firefly-iii/firefly-iii** | Финансовая модель: строгие минорные единицы (целочисленные копейки `BIGINT`, запрет `float`), категории, подкатегории, лимиты, принцип «Сначала заплати себе». |
| **actualbudget/actual** | Бюджетный интерфейс: План / Факт по категориям, прогресс-бары, визуализация остатков и предотвращение перерасхода. |
| **ihatemoney/ihatemoney** | Совместный доступ семьи (до 5 человек): роли, взаиморасчеты и баланс участников (кто за кого платил) с оптимизацией цепочек долга. |
| **invoice2data/invoice2data** | Шаблоны и регулярные выражения для извлечения ИНН, продавца, даты, итоговой суммы и расчёт скоринга уверенности (confidence score). |
| **beancount/beancount** | Дисциплина целостности: строгая верификация сплитов без потери копеек, запрет несогласованных валют и сумм. |

## 📊 Реляционная схема PostgreSQL (17 сущностей)

1. `users` — Профили пользователей, `telegram_id`, язык интерфейса.
2. `family` — Семейная группа, базовая валюта, код приглашения (`invite_code`).
3. `family_members` — Участники семьи (до 5 человек), роли (`owner`, `admin`, `member`), аватары.
4. `categories` — Дерево категорий и подкатегорий, иконки Lucide, цветовая палитра.
5. `tags` — Метки и теги операций.
6. `documents` — Хранилище чеков, sha256-хэш, статус обработки (`review_needed`, `confirmed`).
7. `document_extractions` — Результаты OCR (продавец, ИНН, дата, сумма, уверенность).
8. `document_line_items` — Товарные позиции из чека (наименование, цена, количество).
9. `transactions` — Финансовые операции (расход, доход, перевод, отчисление в копилку `saving`) в целочисленных копейках.
10. `transaction_splits` — Разбивка суммы операции между участниками семьи.
11. `transaction_tags` — Связь Many-to-Many между операциями и тегами.
12. `budgets` — Месячные лимиты категорий (План/Факт, порог предупреждения о перерасходе).
13. `document_comments` — Семейные заметки к чекам и квитанциям.
14. `recurring_rules` — Правила регулярных периодических трат (подписки, ипотека, ЖКХ).
15. `scheduled_payments` — Запланированные платежи на основе регулярных правил (статусы `pending`, `paid`, `skipped`).
16. `savings_goals` (alias `funds`) — Накопительные цели, вклады, депозиты, целевые фонды семьи и прогресс.
17. `audit_logs` — Журнал изменений и аудита действий пользователей.

## 🚀 Быстрый запуск на локальной машине или VPS

### 1. Запуск Web/PWA версии в режиме разработки:
```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev
```
Откройте браузер по адресу `http://localhost:3000`.

---

### 2. Развёртывание на VPS (включая не новые серверы с другими сайтами/сервисами):

> 📖 **Полное пошаговое руководство со всеми деталями доступно в файле [DEPLOY_VPS.md](./DEPLOY_VPS.md)**

#### Шаг 1. Клонирование репозитория на VPS:
```bash
sudo mkdir -p /opt/finsync
sudo chown $USER:$USER /opt/finsync
cd /opt/finsync
git clone https://github.com/ВАШ_АККАУНТ/ВАШ_РЕПОЗИТОРИЙ.git .
```

#### Шаг 2. Экспресс-проверка сервера скриптом диагностики:
Поскольку VPS может быть **не новым** (уже установлены другие сервисы, заняты порты, ограничен RAM или нет Swap), запустите встроенную утилиту предварительной диагностики:
```bash
chmod +x scripts/vps_check_and_setup.sh
./scripts/vps_check_and_setup.sh
```
Скрипт выполнит:
* Проверку наличия Git, Docker, Docker Compose, Nginx и Certbot.
* Проверку RAM, Swap и свободного места на диске (предупредит, если нужен Swap для сборки Vite/Tesseract).
* Сканирование портов (`80`, `443`, `3000`, `8000`, `5432`, `6379`) на конфликты с существующими процессами.
* Интерактивную генерацию файла `.env` с криптостойкими паролями и правами доступа `chmod 600 .env`.

#### Шаг 3. Ручное создание `.env` (если настраиваете без скрипта):
```bash
cp .env.example .env
chmod 600 .env
```
Сгенерируйте стойкие секреты прямо в консоли VPS:
```bash
# Пароли для PostgreSQL и Redis (32 символа):
openssl rand -hex 16

# Секретный ключ JWT (64 символа):
openssl rand -hex 32
```
В файле `.env` укажите:
* `TELEGRAM_BOT_TOKEN` — получен у [@BotFather](https://t.me/BotFather).
* `TELEGRAM_ADMIN_CHAT_IDS` — ваш цифровой ID из [@userinfobot](https://t.me/userinfobot).
* `DOMAIN_NAME` и `APP_URL` — ваш домен (например, `https://budget.yourdomain.ru`).
* `POSTGRES_PASSWORD` и `REDIS_PASSWORD` — сгенерированные пароли.
* `SECRET_KEY` — сгенерированный ключ JWT.

#### Шаг 4. Сборка и фоновый запуск всех микросервисов:
```bash
docker compose up -d --build
```

#### Шаг 5. Проверка статуса и логов:
```bash
# Список запущенных контейнеров:
docker compose ps

# Логи Telegram-бота:
docker compose logs -f telegram_bot

# Логи бэкенда и OCR-воркера:
docker compose logs -f backend ocr_worker
```

#### Шаг 6. Настройка Nginx и бесплатного SSL Let's Encrypt:
Подробный конфиг Nginx для проксирования на порты 3000 и 8000 с поддержкой WebSockets и выпуском SSL-сертификата через `certbot --nginx` подробно описан в **[DEPLOY_VPS.md](./DEPLOY_VPS.md)**.

## 🔒 Безопасность и конфиденциальность

* **100% On-Premise / Local:** Никакие финансовые транзакции, остатки на счетах или сканы чеков не отправляются сторонним облачным провайдерам или LLM.
* **Строгая валидация:** Все входящие данные типизированы TypeScript на клиенте и Pydantic на сервере.
* **Резервное копирование:** Встроенный механизм создания и восстановления дампов БД и JSON-слепков одной кнопкой.
